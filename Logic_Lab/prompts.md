# LLM prompt and notes

LLM assistant used: Claude.

## Prompt (Task 2)

> I want to implement a simple planning agent in Python.
> Represent a state as a set of logical propositions.
> Each action should contain: a name; positive preconditions; negative preconditions; positive
> effects; negative effects.
> An action is applicable if all of its preconditions are satisfied by the current state.
> When an action is applied: 1. remove its negative effects from the state; 2. add its positive
> effects to the state.
> Use breadth-first search to find a sequence of actions that achieves a specified goal.
> The program should also: detect when no plan exists; print the resulting sequence of actions;
> print the states reached after each action.
> Explain the implementation and identify any assumptions you make.
> Run the generated program on the warehouse problem (locations A, B, C; moves A-B and B-C in both
> directions; PickUp and Drop as described; start At(Robot,A), At(Package,A); goal At(Package,C)).

## What was generated by the LLM

* `planner.py`: the `Action` class, `applicable`, `apply_action`, `bfs_plan` and the warehouse actions.
* `tests/test_planner.py` and `run_experiments.py`: the tests and result printing.
* `planner.pl`: the Prolog facts and rules.

## What was added or changed after reading the code

1. **`validate_plan`:** a separate function that replays a plan and checks every precondition
   independently of the BFS code. The planner's own output is not used to check itself.
2. **`check_preconditions` flag in `bfs_plan`:** only for demonstrating the bug in Reflection Q2
   (it lets the planner "deliver" the package with a single `Drop`).
3. **Generalised PickUp/Drop:** the handout only shows `PickUp(Package,A)` and `Drop(Package,C)` as
   examples, so I defined PickUp and Drop for all three locations (an assumption).
4. **Handout example plan:** the example sequence in Task 1 (`Move(A,B), PickUp(Package,B), ...`) is
   not valid because the package is at A, not B. I tested it with the validator and it is rejected
   at step 2; my manual plan is different (see report).
