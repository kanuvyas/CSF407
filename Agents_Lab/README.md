# Agents Lab – Goal-Based Warehouse Agent

A goal-based agent that finds a collision-free shortest path through a warehouse grid using breadth-first search. The code was generated by an LLM (Claude) and then tested (see `REPORT.md`, LLM disclosure).

## How to run (Python 3, standard library only)

```
python3 src/warehouse_agent.py                      # the agent
python3 -m unittest discover -s tests -v            # 19 tests
sh run_all.sh                                       # regenerate everything in results/
```

## Main results

- Shortest path on the lab map: 20 moves, 59 nodes expanded.
- Walled-in goal: "No path exists from S to G".
- All 19 tests pass, and all 5 deliberately broken planners are caught.
- BFS effort grows about 4x each time the warehouse's width and height are doubled.
